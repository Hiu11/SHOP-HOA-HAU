# SHOP HOA HẬU — Logo

- `logo-shop-hoa-hau.svg` / `.png`: chữ xanh đậm, dùng trên nền sáng.
- `logo-shop-hoa-hau-light.svg` / `.png`: chữ kem, dùng trên nền tối.
- SVG: vector, font Lora được nhúng để giữ đúng kiểu chữ tiếng Việt.
- PNG: 1400 × 600, nền trong suốt.

Biểu tượng hoa là Flower 2 nguyên bản của Lucide (ISC), không tự vẽ icon. Kiểu chữ Lora từ Google Fonts (SIL OFL). Giấy phép nằm tại `/lucide-license.txt` và `/fonts/OFL-lora.txt`.

Tạo lại file bằng `npm run brand`.
