# SHOP HOA HẬU — Logo

- `logo-shop-hoa-hau.svg` / `.png`: chữ xanh đậm, dùng trên nền sáng.
- `logo-shop-hoa-hau-light.svg` / `.png`: chữ kem, dùng trên nền tối.
- SVG: chữ HẬU được vẽ bằng đường nét vector, không phụ thuộc font. Dấu mũ và dấu nặng nằm trong hình chữ.
- PNG: 1600 × 800, nền trong suốt.

Logo chữ riêng theo yêu cầu: cành lay ơn tạo nét chữ H, đôi lá tạo dấu mũ của chữ Ậ, nụ hoa tạo dấu nặng, lá kết thúc nét chữ U. Bảng màu xanh vườn, hồng đất và kem. Các icon chức năng trên website vẫn dùng Lucide (ISC).

Thông tin thương hiệu: hoa nhập từ vườn Đà Lạt; chuyên sỉ lay ơn và hướng dương tại Hồ Thị Kỷ, mở cửa 24/24.

Tạo lại file bằng `npm run brand`.
